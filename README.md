# lens-tomography

Research code for testing which components of three-dimensional cluster structure can be recovered from multi-redshift lensing constraints.

This is an open-source research starter repository inspired by an unfinished research direction on three-dimensional imaging and reconstruction with gravitational lensing.

## Status

Early research scaffold. The immediate goal is a small, reproducible experiment before expanding scope.

## Principles

- Reproducible simulations and notebooks
- Publicly available astronomical data where possible
- Explicit uncertainty and degeneracy analysis
- Tested scientific code
- Clear separation between visualization and physical inference

## Core research question

Given strongly lensed systems at several source redshifts, what genuinely three-dimensional information is recoverable about the lensing mass distribution, and what remains fundamentally degenerate?
